# A43 결과: 동적 설정을 고르는 규칙은 시간 밖으로 전달되지 않았다 (2026-11-11)

자산배분 DECISIONS A43. 설계 `2026-11-06_a43_design.md`(실행 전에 고정, 바꾼 점 없음). 코드 `lab/aa_timesplit.py`, 실행 `scripts/aa_a43_timesplit.py --check-stage4`(랩 PC, 2026-11-11 01:45 – 01:55 KST, 605초), 결과 `2026-11-06_a43_timesplit/`, 그림 `figures/a43_timesplit/`.

## 왜 했는지

A42 4단계는 연구 구간 전체(2000-09 – 2024-12)에서 동적 설정 15,714개(대상 6 × 설정 873 × 위성 0·25·50%)에 판정 세 개(① 가짜 신호 200개의 95%보다 MDD 개선, ② 같은 비용 정적보다 MDD 3%p 이상 얕음, ③ CAGR 손실 1%p 이하, 극단 두 세트에서 ② 유지)를 걸어 113개를 남겼고, 5단계가 그중 대표를 뽑았다. ③((가) + K2 카나리아 → 안전 묶음 + 변동성 목표 8% + 위성 50%)은 가짜 신호 선을 0.14%p로 넘은 한 칸짜리 봉우리였다. 그래서 그 주변을 뒤지는 대신 고르는 절차 자체를 시험했다. 같은 경로를 고정 구간으로 잘라, 한 구간에서 4단계 규칙으로 고르고 다른 구간에서 성적을 봤다(네 방향).

## 핵심 결과

**1. 재현 점검은 통과했다.** '전체' 구간의 판정은 4단계 `verdicts.csv.gz`와 15,714행 중 15,712행이 같다. 다른 2행은 같은 설정 묶음(현재 보유 + D1 → CD, 확인 10, 4분할, 변동성 8%, 위성 50%)의 쿨다운 0·21인데, 둘 다 MDD가 가짜 신호 95% 선과 소수 여섯째 자리까지 같아(−10.288%) 1e-7 수준의 가격 차이로 동점이 반대로 갈렸다. CAGR·MDD 차이는 최대 1.3e-6이다.

**2. J1(규칙 A, 통과한 설정 전부): 없음.** 네 방향 모두 고르는 구간의 통과 설정 중 시험 구간에서도 통과한 것이 0개다.

| 방향 | 고르는 구간 통과 | 시험 구간에서도 통과 | 시험 구간 바탕 통과율 |
|---|---|---|---|
| ㉮ 전반 → 후반 | 477 | 0 | 0% (후반은 아무것도 통과 못 함) |
| ㉯ 후반 → 전반 | 0 | — | 3.0% |
| ㉰ 1+2구간 → 3구간 | 406 | 0 | 0.006% (1개) |
| ㉱ 2+3구간 → 1구간 | 55 | 0 | 4.4% |

구간별 통과 수가 핵심을 보여 준다: 1구간(2000-09 – 2008-12) 699, 전반 477, 2구간 95, 3구간(2017 – 2024) 1, 후반(2013 – 2024) 0. **4단계 판정을 통과하게 만든 것은 거의 전부 닷컴 붕괴와 2008년이다.** 2013년 이후에는 15,714개 설정 중 어느 것도 가짜 신호를 이기면서 낙폭을 3%p 줄이고 수익을 지키지 못했다. ㉱에서는 오히려 거꾸로다: 2009 – 2024에서 고른 55개는 1구간에서 하나도 통과하지 못했는데, 아무것이나 고르면 4.4%가 통과한다.

판정을 하나 풀어 ①③만 보면(낙폭 3%p 조건 없이) ㉮의 유지율은 0.6%로 바탕 3.1%보다 낮다. 고른 설정은 후반에도 MDD를 중앙값 3.1%p 줄였지만(나머지 0.3%p) CAGR을 1.35%p 내줬고, 그 낙폭 개선도 가짜 신호보다 낫지 않았다.

**3. J2(규칙 B, (가)에서 순위값 1위 하나): 무너짐.** ㉮에서 고른 K2 카나리아 + 변동성 목표 10% + 위성 50%는 후반에 MDD 개선 2.99%p(기준 3%p), 가짜 신호 대비 백분위 5%로 ①②를 놓쳤다. ㉰에서 고른 D1 나스닥 추세 → CD + 변동성 8% + 위성 25%는 3구간에서 CAGR을 1.29%p 잃어 ③을 놓쳤다. ㉯·㉱는 고르는 구간에서 (가)의 통과 설정이 없었다.

**4. J3(③ 자체): 탈락.** ③은 전반(10.00% / −8.7%)에서 통과하지만 후반(7.99% / −8.5%)에서 ①(가짜 신호 95% 선 −7.90%보다 깊음)·②(같은 비용 정적 −8.38%보다 얕지 않음)·극단 세트에서 모두 탈락한다. 같은 후반에 (가) 정적은 8.60% / −12.2%, 신호 없는 '(가) 50 + 위성 50'은 8.76% / −9.2%다. ③의 후반 낙폭 개선은 대부분 위성 몫이고, 동적 층이 더한 것은 MDD 0.7%p 개선과 CAGR 0.8%p 손실의 맞바꿈이다.

### 미리 정한 읽는 법에 따른 결론

J1 없음 · J2 무너짐이므로 **4·5단계의 선택은 시간 밖으로 전달되지 않았고, ③의 동적 부품(K2 카나리아, 변동성 목표와의 조합)은 검증된 발견이 아니다.** 같은 판정이 여섯 대상 모두에 적용되므로 ②(D1 → CD), ⑤(K3 HAA → CD)의 신호 부분도 마찬가지다.

설계는 남는 것을 '두 절반 모두에서 −15% 안인 신호 없는 기준'으로 정해 두었다. 후보는 둘이었다.

- '(가) 50 + 위성 50'(신호 없음): 전반 9.17% / −12.3%, 후반 8.76% / −9.2%. 그러나 같은 날 끝난 A44에서 위성 결정일을 옮기면 −19.6%까지 깊어져 탈락했다.
- 변동성 목표만: (가) + 변동성 목표 8%는 전반 7.74% / −12.9%, 후반 8.39% / −10.5%로 두 절반 모두 안이지만 (가) 정적보다 CAGR이 0.7%p 낮다. R6 + 변동성 목표 10%(5단계 참고 행)는 전반 6.55% / −7.7%, 후반 7.76% / −7.4%, 1990년대 −10.3%로 낙폭이 가장 안정적이다.

정적 (가)는 전반 8.97% / −13.7%, 후반 8.60% / −12.2%, 안정형 40은 7.81% / −13.7%, 7.72% / −11.8%로 두 절반 모두 −15% 안이다.
