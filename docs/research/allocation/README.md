# 자산배분 연구실 사용법

추세추종 연구실과 **별도 앱**입니다 (`lab/aa_app.py`, 포트 8511). 종목 선택 규칙이 아니라 **자산 비중·리밸런싱·전술 overlay·레버리지·전략 믹스**를 시험합니다.

## 시작

- 저장소 폴더에서 **`자산배분 연구실 시작.cmd`** 더블클릭. Python 환경은 추세추종 연구실과 같은 `.venv`를 씁니다.
- Chrome 북마크로 열려면 **`자산배분 연구실 북마크 등록.cmd`** 를 한 번 실행한 뒤, 북마크 URL을 `aalab://scorecard`로 만듭니다
  (`aalab://research` 전략 연구, `aalab://notes` 발견·경고·캠페인, `aalab://saved` 저장된 전략). 앱이 꺼져 있으면 최소화된 창으로 켜고 페이지를 엽니다.
  이 창을 닫으면 앱이 꺼집니다. 추세추종 연구실(`trendlab://`, 8501)과 동시에 켜 둘 수 있습니다.

## 화면

1. **전략 연구** — 프리셋(내 AAA, 60/40, 올웨더, 영구, 골든버터플라이, GTAA 5 …)을 불러오거나 자산과 비중을 직접 넣습니다.
   리밸런싱 주기(매월·매분기·매년·안 함)와 밴드, 거래비용, overlay(추세 필터·절대 모멘텀·듀얼 모멘텀·리스크 패리티·변동성 목표), 레버리지(전체 배수, 자산별 배수, 조달 스프레드, 추가 보수)를 정하고 실행합니다.
   결과: CAGR·MDD·현금 초과 샤프·칼마·최악 12개월·CVaR·회전율·평균 노출, 탐색/최종 Gate, 자산 곡선·낙폭·연도별 수익·비중 변화·위기 구간 표. 저장하면 성적표에서 비교할 수 있습니다.
2. **성적표 · 믹스** — 프리셋·저장 전략·현재 화면 전략을 **같은 기간**에 다시 돌려 아홉 축 점수(0–100, 비교 집합 안의 백분위 순위)를 히트맵으로 봅니다.
   '믹스 만들기'에서 전략 2–5개를 비율로 섞어 한 줄로 추가합니다(각 슬리브는 따로 운용, 슬리브 비율은 정한 주기로 복원).
3. **발견 · 경고 · 캠페인** — `docs/research/allocation/NOTES.md`의 세 절을 보여 주고 항목을 추가합니다. 아래에는 이 연구실에서 실행한 기록(`lab_results/aa_runs.csv`)이 쌓입니다.
4. **저장된 전략**, 5. **용어 설명**.

## 성적표의 아홉 축

| 축 | 원래 값 | 방향 |
|---|---|---|
| 단순 | 자유 파라미터 수 (비중 1 + 주기·밴드·overlay·레버리지마다 1) | 적을수록 |
| 일관 | 36개월 구간 중 현금을 이긴 비율 | 높을수록 |
| 위기 | 등록된 위기 구간(닷컴·금융위기·2011·2018Q4·코로나·2022)에서 전략 − SPY 수익률 평균 | 높을수록 |
| 꼬리 | 월간 수익률 CVaR 5% | 0에 가까울수록 |
| 비용 | 연간 회전율 × 거래비용 + 레버리지 조달·보수 | 낮을수록 |
| 샤프 전반 / 후반 | 기간 전반·후반의 현금 초과 샤프 | 높을수록 |
| 최대낙폭, 칼마 | 추세추종 연구실과 같은 계산 | |

'견고'는 축 점수의 가중 평균(기본 동일)으로 **참고용**입니다. 판정은 Gate로 합니다:
탐색 Gate = 칼마 ≥ SPY 칼마 그리고 |MDD| ≤ 0.75×|SPY MDD|, 최종 Gate = CAGR ≥ 0.8×SPY CAGR 그리고 |MDD| ≤ 0.75×|SPY MDD|.

## 한계 (모든 결과에 공통)

- 미국 상장 ETF의 **달러 수익률**입니다. KODEX 등 국내 상품의 환율, 헤지 비용, 보수, 추적오차, 세금은 들어 있지 않습니다.
- 데이터는 대부분 2004–2005년부터라 2000–02년 하락장은 일부 자산(SPY·QQQ·EFA·EEM·TLT·IEF 등)만 포함합니다. 금(GLD)은 2004-11부터입니다.
- 1980–2020년 채권 강세장이 채권 비중이 큰 전략의 수익을 부풀립니다. 스태그플레이션 샘플은 2022년 하나입니다.
- 레버리지는 일일 리셋 모형이며 조달 스프레드·보수는 입력값입니다. 합성 ETF의 스왑 비용·호가 차이는 따로 반영하지 않습니다.
- 표본 내(in-sample) 연구입니다. 프리셋과 위기 구간은 2026-10-24에 등록했고 결과를 보고 고치지 않습니다.
