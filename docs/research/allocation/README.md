# 자산배분 연구실 사용법

추세추종 연구실과 **별도 앱**입니다 (`lab/aa_app.py`, 포트 8511). 종목 선택 규칙이 아니라 **자산 비중·리밸런싱·전술 overlay·레버리지·전략 믹스**를 시험합니다.
ISA 계좌에서 살 수 있는 **국내 상장 ETF**를 단위로 쓰고, 모든 결과는 **원화 수익률**입니다(2026-10-24부터, DECISIONS A13).

## 시작

- 저장소 폴더에서 **`자산배분 연구실 시작.cmd`** 더블클릭. Python 환경은 추세추종 연구실과 같은 `.venv`를 씁니다.
- Chrome 북마크로 열려면 **`자산배분 연구실 북마크 등록.cmd`** 를 한 번 실행한 뒤 북마크 URL을 아래 중 하나로 만듭니다.
  앱이 꺼져 있으면 최소화된 창으로 켜고 페이지를 엽니다. 이 창을 닫으면 앱이 꺼집니다. 추세추종 연구실(`trendlab://`, 8501)과 동시에 켜 둘 수 있습니다.

## 화면

1. **전략 연구** — 처음 열면 내 AAA(2026-06 배분)가 들어 있습니다. 프리셋을 불러오거나, 자산군별 **체크박스**로 상품을 고르고 **슬라이더**로 비중(%)을 정합니다.
   '합계 100으로 맞추기'·'동일 비중' 버튼, 합계 경고, 가중 평균 총보수, 배분 막대가 같이 보입니다. 상품 이름에 마우스를 올리면 종목코드·보수·상장일·대용 데이터가 나옵니다.
   기간(전체·2010·2015·2020 이후·**실제 상장일 이후만**·직접 지정), 리밸런싱 주기와 밴드, 거래비용, overlay(추세 필터·절대 모멘텀·듀얼 모멘텀·리스크 패리티·변동성 목표)와 안전자산(현금·CD금리·달러선물·미국10년·미국30년·금현물)을 정하고 실행합니다.
   결과: S&P500(원화) 대비 CAGR·MDD·샤프·칼마 카드, 탐색/최종 Gate, 자산 곡선·낙폭·연도별 수익·비중 변화·위기 구간 표, 그리고 **ISA 매수 목록**(상품·코드·비중·금액·환헤지 여부·총보수·상장일).
2. **전략 비교** — 전략 연구와 성적표에서 **실행한 모든 전략**(같은 설정은 한 번만)과 저장한 전략, 원하면 프리셋까지 같은 기간으로 다시 돌려 한 표에 CAGR·MDD·샤프·칼마·변동성·최악 12개월·Gate를 보여 줍니다.
   수익·낙폭 지도(점선 = Gate 경계)에 모든 전략이 점으로 찍히고, 표의 '선택'을 켠 전략은 자산 곡선·낙폭·연도별 수익을 겹쳐 그립니다.
3. **성적표 · 믹스** — 프리셋·저장 전략·현재 화면 전략을 **같은 기간**에 다시 돌려 아홉 축 점수(0–100, 비교 집합 안의 백분위 순위)를 히트맵으로 봅니다.
   '믹스 만들기'에서 전략 2–5개를 슬라이더 비율로 섞어 한 줄로 추가합니다(각 슬리브는 따로 운용, 슬리브 비율은 정한 주기로 복원).
4. **리밸런싱 계산기** — 목표 전략(프리셋·저장 전략·전략 연구 화면)을 고르고, 지금 ISA의 상품별 평가금액(원하면 현재가)과 이번 입금액을 넣으면 상품별 매수·매도 금액과 주 수를 계산합니다.
   '입금액만으로 맞추기(매도 없음)'가 기본이고, '전체 리밸런싱'은 밴드 안이면 팔지 않습니다. 보유 내역은 이 컴퓨터의 `lab_results/aa_holdings.json`에만 저장됩니다.
5. **발견 · 경고 · 캠페인** — `docs/research/allocation/NOTES.md`의 세 절을 보여 주고 항목을 추가합니다. 아래에는 실행 기록(`lab_results/aa_runs.csv`)이 쌓입니다.
6. **저장된 전략**, 7. **용어 · 상품 설명**(상품 20종의 코드·환헤지·보수·상장일·대용 데이터 표 포함).

사이드바에는 데이터 기간(미국 대용 ETF, 원/달러, 기준금리)과 **환헤지 추가 비용(bp/년)** 슬라이더가 있습니다.

## 상품과 원화 수익률

상품 목록은 `lab/aa_assets.py`의 `PRODUCTS`입니다(2026-10-24 확인: etfshopping.com, funetf, 운용사 페이지). 대부분 2015년 이후 상장이라 상장 전은 미국 ETF로 만든 **대용 데이터**입니다.

| 환 처리 | 원화 일간 수익률 | 예 |
|---|---|---|
| 환노출 | (1 + 미국 ETF 수익률) × (1 + 원/달러 변화) − 1 − 보수 | KODEX 미국S&P500, MSCI선진국, ACE KRX금현물 |
| 환헤지(H) | 미국 ETF 수익률 − 달러 단기금리 + 원화 단기금리 − 추가 헤지 비용 − 보수 | 미국30년·10년국채액티브(H), EM선물(H) |
| 원화(국내 주식) | EWY를 원화로 환산 | KODEX 200, KODEX 레버리지 |
| 원화 현금 | 한국은행 기준금리 − 보수 | KODEX CD금리액티브 |
| 레버리지 | 배수 × (수익률 − 조달 통화 단기금리) + 단기금리, 매일 리셋 | TIGER 미국S&P500레버리지 등 6종 |

- 원/달러: FRED DEXKOUS(뉴욕 정오 환율, 미국 종가와 같은 시각) → `lab/aa_usdkrw.csv.gz`. 갱신은 `.venv/Scripts/python.exe -m lab.aa_korea refresh`, 앱은 인터넷이 되면 Yahoo(KRW=X)로 최근 며칠을 잇습니다.
- 원화 단기금리: 한국은행 기준금리 일정표 `lab/aa_bok_rate.csv`. 2018-11 이전 행은 ECOS 원자료와 아직 대조하지 않았습니다.
- 기준선(벤치마크)은 **KODEX 미국S&P500(379800, 환노출)의 원화 수익률**이고, 남는 현금은 원화 단기금리를 받습니다.

## 성적표의 아홉 축

| 축 | 원래 값 | 방향 |
|---|---|---|
| 단순 | 자유 파라미터 수 (비중 1 + 주기·밴드·overlay·레버리지마다 1) | 적을수록 |
| 일관 | 36개월 구간 중 현금을 이긴 비율 | 높을수록 |
| 위기 | 등록된 위기 구간(닷컴·금융위기·2011·2018Q4·코로나·2022)에서 전략 − S&P500(원화) 수익률 평균 | 높을수록 |
| 꼬리 | 월간 수익률 CVaR 5% | 0에 가까울수록 |
| 비용 | 연간 회전율 × 거래비용 + 레버리지 조달·보수 | 낮을수록 |
| 샤프 전반 / 후반 | 기간 전반·후반의 현금 초과 샤프 | 높을수록 |
| 최대낙폭, 칼마 | 추세추종 연구실과 같은 계산 | |

'견고'는 축 점수의 가중 평균(기본 동일)으로 **참고용**입니다. 판정은 Gate로 합니다(기준선 = S&P500 원화):
탐색 Gate = 칼마 ≥ 기준선 칼마 그리고 |MDD| ≤ 0.75×|기준선 MDD|, 최종 Gate = CAGR ≥ 0.8×기준선 CAGR 그리고 |MDD| ≤ 0.75×|기준선 MDD|.

## 한계 (모든 결과에 공통)

- 상장 전 기간은 **대용 데이터**입니다. 실제 국내 ETF의 괴리율·추적오차, 국내 금 프리미엄(KRX 금값이 국제 금값보다 비싼 구간), 분배금 시점은 없습니다.
- 환헤지 비용은 두 나라 단기금리 차 + 연 20bp로 가정했습니다. 원화 단기금리는 기준금리라 실제 CD 금리보다 0.1–0.5%p 낮습니다.
- 세금은 모형에 없습니다. ISA는 만기 정산 때 비과세 한도 초과분만 9.9% 분리과세라, 계좌 안의 매매·분배금 과세는 결과에 큰 차이를 만들지 않는다고 가정합니다.
- TIGER 미국S&P500레버리지는 배당을 빼고 추종해 연 3%p를, ACE 미국30년국채선물레버리지는 실제 듀레이션이 대용(TLT 2배)보다 길다는 점을 주의하세요.
- 대용 데이터는 대부분 2004–2005년부터라 2000–02년 하락장은 일부 자산만 포함합니다. 금(GLD)은 2004-11부터입니다.
- 1980–2020년 채권 강세장이 채권 비중이 큰 전략의 수익을 부풀립니다. 스태그플레이션 샘플은 2022년 하나입니다.
- 원화 기준선은 달러 SPY보다 낙폭이 훨씬 작아(2005–2026 −29.6% vs −55.2%) Gate의 MDD 기준이 달러 시절보다 엄격합니다. 이전 노트의 달러 숫자와 직접 비교하지 마세요.
- 표본 내(in-sample) 연구입니다. 프리셋과 위기 구간은 결과를 보고 고치지 않습니다.
