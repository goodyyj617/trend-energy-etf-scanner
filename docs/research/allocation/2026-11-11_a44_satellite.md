# A44 결과: ②·③ 안의 위성 50%는 결정일과 비용을 바꾸면 버티지 못했다 (2026-11-11)

자산배분 DECISIONS A44. 설계 `2026-11-11_a44_design.md`(실행 전에 고정, 바꾼 점 없음). 코드 `lab/aa_satellite.py`, 실행 `scripts/aa_a44_satellite.py`(랩 PC, 2026-11-11 01:44 KST, 40초), 결과 `2026-11-11_a44_satellite/`, 그림 `figures/a44_satellite/`.

## 왜 했는지

등록 동적 프리셋 ②(현재 보유 + D1 나스닥 추세 → CD + 위성 50%)와 ③((가) + K2 카나리아 → 안전 묶음 + 변동성 목표 8% + 위성 50%)은 자산의 절반을 위성(HAA 50 + BAA 공격형 G4 50, 국내 상품판)에 둔다. 11-10 점검에서 A42 5단계의 정책 변형이 본체만 옮겼고, 위성은 '월말 결정 한 경로, 본체와 섞는 비용 0'으로만 잰 것을 코드에서 확인했다. 위성 단독은 A30의 날짜 견고 기준을 통과하지 못한 전략이었다(A28: −16 – −33%). 그래서 본체는 등록 그대로 두고, 위성의 결정일(월말 +0/+1/+5/+10/+15거래일, 4분할), 교체 비용(10/20bp), 본체와 섞는 방식(매일 무료 / 월말·분기 말 복원 10bp)만 바꿔 같은 조합을 다시 쟀다.

## 핵심 결과

**1. 재현은 맞았다.** 월말 결정 · 10bp · 매일 고정 비율 · 50%는 5단계 숫자와 같다(③ 9.07% / −8.71%, ② 8.84% / −10.29%, 차이 1e-6 미만). 아래 차이는 계산 차이가 아니라 위성 결정일의 차이다.

**2. 미리 정한 판정으로 네 조합 모두 탈락이다.** 판정 조건(대표 세트, 2000-09 – 2024-12, 위성 50%, 분기 말 복원 10bp, 위성 교체 10bp)에서 결정일 다섯 개의 결과는 이렇다.

| 조합 | 월말 | +1 | +5 | +10 | +15 | 4분할 | 위성 없는 같은 본체 |
|---|---|---|---|---|---|---|---|
| ③ (가) + K2 + 변동성 8% + 위성 | 9.03 / −8.7 | 8.98 / −10.0 | 8.19 / −9.7 | 8.10 / **−17.9** | 9.06 / −9.9 | 8.69 / −10.1 | 8.25 / −11.0 |
| (가) + 위성, 신호 없음 | 8.97 / −12.3 | 8.93 / −12.3 | 8.13 / −12.3 | 8.03 / **−19.6** | 9.00 / −12.3 | 8.63 / −12.3 | 8.81 / −13.7 |
| ② 현재 보유 + D1 + 위성 | 8.80 / −10.2 | 8.76 / −13.1 | 7.99 / −13.8 | 7.85 / **−23.9** | 8.82 / −15.7 | 8.44 / −15.7 | 7.73 / −16.8 |
| 현재 보유 + 위성, 신호 없음 | 8.61 / −17.5 | 8.56 / −17.5 | 7.80 / −17.5 | 7.66 / **−23.9** | 8.61 / −17.5 | 8.24 / −17.5 | 8.01 / −17.5 |

(CAGR % / MDD %.) W1(최악 결정일 MDD ≥ −20%)은 ③과 '(가) + 위성'만 통과했고, W2는 넷 모두 '밖'(최악이 −17%보다 깊음), W3(20bp에서 위성이 같은 본체보다 CAGR을 다섯 결정일 중 넷 이상에서 높이고 최악 MDD를 1%p 넘게 키우지 않음)는 넷 모두 실패했다. 넷 모두 '날짜 민감'(MDD 폭 6–14%p)이다. 극단 가격 세트 두 개에서도 네 조합 모두 같은 판정이다.

**3. 무너지는 날은 +10거래일 하나이지만, 수익은 결정일마다 1%p씩 흔들린다.** MDD는 다섯 결정일 중 +10일 때만 크게 깊어진다(위성 단독 −32.2%). 그러나 CAGR은 월말·+1·+15가 9.0% 근처, +5·+10이 8.0–8.2%로 갈린다. 위성 단독의 CAGR도 결정일에 따라 8.0 – 10.5%다. 어느 결정일이 좋은지는 미리 알 방법이 없고, 그 차이가 ③과 (가) 정적 사이의 차이(0.26%p)보다 몇 배 크다. ③의 9.07% / −8.7%는 다섯 결정일 중 가장 운 좋은 쪽의 숫자였다.

**4. 4분할로 결정일 운을 평균하면, 위성은 수익 대신 낙폭을 조금 줄이는 쪽이다.** 4분할(위성 돈을 넷으로 나눠 +0/+5/+10/+15에 결정)은 ③ 8.69% / −10.1%, '(가) + 위성' 8.63% / −12.3%로 둘 다 −15% 안이다. 그러나 '(가) + 위성' 4분할은 (가) 정적(8.81% / −13.7%)보다 CAGR이 0.18%p 낮고 MDD가 1.4%p 얕다. ③ 4분할은 ③ 본체(8.25% / −11.0%)보다 0.44%p 높지만 (가) 정적보다는 0.12%p 낮다. 즉 5단계에서 '③의 CAGR 우위는 위성 몫'이라고 읽었던 것은 월말 결정의 운이었고, 운을 평균하면 우위는 사라진다.

**5. 섞는 방식의 비용은 작다.** 매일 무료로 되돌리는 것(5단계)과 분기 말 10bp로 되돌리는 것의 차이는 CAGR 0.04 – 0.06%p다. 문제는 섞는 비용이 아니라 결정일이었다.

**6. 위성 몫 25%(참고)도 +10에서 같은 모양이다.** ③ −11.2%, ② −19.6%, '(가) + 위성' −13.7%.

### 미리 정한 읽는 법에 따른 결론

- ③ 탈락: ②·③의 숫자는 '월말 결정 한 경로의 숫자'로 낮춰 적고, 위성이 든 조합은 권고에서 뺀다(한눈에 보는 결론, 동적 프리셋 설명). 남는 비교 대상은 (가) 정적과, 위성 없는 본체(③ 본체 8.25% / −11.0%)다.
- 4분할만 '안'인 경우(③, '(가) + 위성'): 설계대로 '4분할로만 운용 가능'으로 적는다. 다만 W3 실패가 보여 주듯 4분할의 위성은 (가) 정적보다 수익을 더하지 않는다. 쓸 이유는 MDD 1–3%p뿐이고, 그 대가로 매달 네 번의 위성 매매가 든다.
- 가장 좋은 결정일(+15)을 고르지 않는다. 그것이 이 실험이 막으려는 선택이다.

## 한계

- 위성은 2007-02 이후에만 존재한다. 위성이 겪은 위기는 2008 – 2009, 2020, 2022뿐이다. 위성 구간(2007-04 – 2024-12)만 따로 재도 판정은 같다(`verdicts.csv`).
