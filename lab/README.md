## 화면 흐름 (위에서 아래로)

1. **유니버스와 기간**
   - 데이터는 세 가지 중 고릅니다.
     - ETF 스냅샷: 466개, 2016~2026년, 인터넷 불필요
     - 장기 멀티에셋 ETF: 38개, 1993년~현재, 2000년·2008년 하락장 포함
     - 직접 입력: ETF·개별 종목
   - ETF는 **필터 깔때기**를 거칩니다. 화면에 단계별 남은 개수가 보입니다.
     1. 현금성 ETF 제외
     2. 자산군 선택
     3. 운용 규모 하한
     4. 총보수 상한
     5. 중복 ETF 정리 (사실상 같은 상품은 큰 것만 남김)
   - 🔒 **보류 구간**(기본 2024-01-01 이후)은 연구에 쓰지 않으므로, 종료일은 그 전날까지만 고를 수 있습니다.
2. **진입 조건**: 체크한 조건이 *모두* 참이면 다음 날 시가에 매수합니다. 조건은 가격, 거래량, 보조지표(RSI·볼린저·Williams %R) 그룹으로 나뉩니다.
3. **청산 조건**: 체크한 조건 중 *하나라도* 참이면 다음 날 시가에 매도합니다. ATR 트레일링 스톱도 있습니다.
4. **포트폴리오·비용·현금**: 최대 보유 종목 수, 편도 비용, 유동성 필터(20일 또는 60일 평균 거래대금), 남는 현금의 국채 수익률 적용 여부.
   - **포지션 크기**: 기본은 **변동성 역가중**입니다. 잔잔한 종목은 더 많이(최대 2배), 출렁이는 종목은 적게 사서 종목마다 위험을 비슷하게 맞춥니다.
   - 동일 금액도 고를 수 있습니다.
5. **📈 백테스트 탭**
   - 핵심 성과 카드 8개: 누적 수익률, CAGR, MDD, 샤프, 칼마, 소르티노, 최악 12개월, DSR
   - **기준선 비교표**: SPY 보유, SPY 200일선, 유니버스 동일비중
   - 자산 곡선, 낙폭, 연도별 수익률
   - Gate(최소 통과 조건)와 **강건성 점검**(7개 항목 통과/미달)
   - 거래 통계(보조)
6. **🧭 강건성 격자 탭**: 파라미터 1–2개를 범위로 바꿔 가며 실행합니다. 히트맵(✓ = 통과), 연결 영역, 이웃 생존율, LOYO를 봅니다.
7. **🧩 전략 계열 비교 탭**: 미리 정해 둔 메뉴(진입 3종 × 청산 3종 = 9개 계열)를 각각 6×6 격자로 한 번에 돌립니다(수 분).
   - 계열은 **격자 전체 성적**으로 순위를 매깁니다: Gate 통과 비율 → 가장 큰 연결 영역 → SPY 200일선을 이긴 칸 비율 → 중간 칼마.
   - "계열 지도"로 어떤 진입·청산 조합이 넓게 통하는지 한눈에 봅니다.
   - 계열을 골라 격자를 자세히 보고, 한 칸을 바로 단일 백테스트로 열 수 있습니다.
   - 메뉴 값은 결과를 보기 전에 정했습니다. 결과를 보고 고치지 않는 것이 핵심입니다.
8. **🧪 확인 조건 시험 탭**: 고른 계열에 확인 조건(RSI, 거래량, 시장 추세 등)을 하나씩 기본값으로 더해 같은 격자를 다시 돌립니다.
   - 네 기준 모두에서 같거나 낫고 하나 이상 나아야 '개선'입니다.
   - 여러 유니버스에서 모두 개선일 때만 조건을 채택하세요.
9. **🔒 최종 검증**: 저장한 전략을 보류 구간에 **그대로** 한 번 적용해 봅니다. 평가 횟수와 기록이 남습니다.
10. **💾 저장된 결과**: 백테스트·격자·계열 비교·확인 조건 시험을 다시 봅니다.
11. **📖 용어 설명**: 모든 지표·조건·블록·필터의 정확한 정의와 계산식.

왼쪽 아래에는 **지금까지 시험한 전략 수**가 표시됩니다. 많이 시험할수록 우연히 좋은 결과가 나오기 쉬우므로, DSR이 이 숫자를 반영해 엄격해집니다.

## 과최적화를 막는 장치 요약

| 장치 | 무엇을 막나 |
|---|---|
| 보류 구간 | 연구에 쓴 데이터로만 판단하는 것 |
| 시험 횟수 기록 + DSR | 많이 시도해서 우연히 좋은 것을 고르는 것 |
| 주변 파라미터·격자 연결 영역 | 특정 숫자 하나에서만 좋은 것 |
| LOYO·전반부/후반부 | 특정 연도·시기에만 좋은 것 |
| 비용 2배 | 비용 가정에 민감한 것 |
| 기준선(SPY 200일선) 비교 | 복잡하기만 하고 단순한 규칙보다 나을 게 없는 것 |

## 현금 대용 자산

도구는 남는 현금이 **BIL(1~3개월 미국 국채 ETF)** 수익률을 받는다고 가정합니다. BIL은 역사가 가장 길어서(2007년 상장) 기준으로 썼고, 그 이전 구간은 13주 국채금리로 채웁니다.
실제 운용에서는 SGOV·BIL·SHV 같은 단기국채 ETF가 비슷한 역할을 합니다. 상품 선택은 수수료·규모·분배 방식·세금을 직접 비교해서 판단하세요.
