## 화면 흐름 (위에서 아래로)

1. **데이터와 기간**: ETF 스냅샷(오프라인 466개 ETF) 또는 티커 직접 입력(ETF·개별 종목). 자산군으로 거래 대상을 고르고, 시작일·종료일을 정합니다.
2. **진입 조건**: 체크한 조건이 *모두* 참이면 다음 날 시가에 매수.
3. **청산 조건**: 체크한 조건 중 *하나라도* 참이면 다음 날 시가에 매도.
4. **포트폴리오와 비용**: 최대 보유 종목 수, 편도 비용, 유동성 필터.
5. **📈 백테스트 탭**: 실제 사용된 기간, SPY 대비 성과, 최소 통과 조건(Gate) 충족 여부, 자산 곡선, 낙폭, 연도별 수익, 거래 통계(보조).
6. **🧭 강건성 격자 탭**: 파라미터 1–2개를 범위로 바꿔 가며 반복 실행합니다. 히트맵(✓ = Gate 통과), 연결 영역, 이웃 생존율, 한 해씩 빼고 재검사(LOYO)를 보고 후보를 고릅니다. 후보의 "이 값으로 설정 + 실행"을 누르면 단일 백테스트로 자세히 볼 수 있습니다.
7. **💾 저장된 결과**: 저장한 백테스트의 자산 곡선을 겹쳐 비교하고, 저장한 격자를 다시 봅니다.
8. **📖 용어 설명**: 모든 지표·조건·블록의 정확한 정의와 계산식.

## "강건하다"의 정의 (이 도구에서)

- **Gate**: CAGR ≥ 0.80 × SPY CAGR, |MDD| ≤ 0.75 × |SPY MDD|, 완료 거래 ≥ 30. 하나라도 못 넘으면 탈락.
- **연결 영역**: Gate 통과 셀이 격자에서 상하좌우로 이어진 덩어리. 크기가 클수록 "고립된 한 점"이 아니라는 뜻.
- **이웃 생존율**: 바로 옆 셀 중 Gate를 통과한 비율.
- **LOYO**: 한 해씩 빼고 다시 판정했을 때 통과하는 비율. 특정 연도 하나에 기대고 있는지 확인.
- 후보는 연결 영역 크기 → 이웃 생존율 → LOYO → 칼마 비율 순으로 정렬합니다. 가중 점수는 쓰지 않습니다.
